**Dream Catcher** | Node.js, Express, PostgreSQL, OpenAI API, JavaScript
- **Engineered** a RESTful full-stack application using Node.js and Express to seamlessly record dreams and generate AI-driven interpretations via the OpenAI API.
- **Architected** a robust backend integrating PostgreSQL for persistent data storage, comprehensive input validation, and centralized error handling for third-party API dependencies.
- **Hardened** application security utilizing Helmet for HTTP headers and optimized API resilience with graceful degradation during AI service downtime.
